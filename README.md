## Agent Research

- [Constraint Decay — LLM Agents Lose 30 Points in Structural Correctness as Requirements Accumulate (arXiv, 183 HN Points)](https://arxiv.org/abs/2605.06445) — Research paper evaluating coding agents across 80 tasks and 8 web frameworks. Key finding: agents pass functional tests but silently shed non-functional constraints (ORM conventions, architectural patterns, database models) as complexity grows. Capable configs lose 30 points from baseline to fully specified tasks. Weaker configs collapse to zero. Flask agents succeed; Django/FastAPI agents fail. Root cause: data-layer defects (incorrect queries, ORM violations).
- [Cattle Trade — Adversarial Agent Benchmark: LLMs in Auctions, Bargaining and Bluffing (arXiv)](https://arxiv.org/abs/2605.14537) — New arXiv paper (2605.14537) dropping LLM agents into adversarial market scenarios: auctions, bargaining, bluffing. Tests multi-agent behavior under adversarial conditions rather than cooperative task completion. Every other benchmark asks "did it finish the task." This one asks "did it read the opponent."
